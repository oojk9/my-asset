# 내 자산관리 (v1.6.1)

예금·적금·투자·부동산·대출 같은 **내 자산**과 **매일의 가계부**를 기록해서
**순자산(총자산 − 총부채)** 을 한눈에 보는 개인용 앱입니다.
갤럭시(안드로이드) 크롬에서 **홈 화면에 설치**해 앱처럼 쓰는 웹앱(PWA)이에요.

## 이 앱이 하는 일

- **홈**: 순자산 · 총자산 · 총부채, 자산 구성 비율, 이번 달 수입/지출, 최근 기록
- **자산**: 현금·통장 / 예금 / 적금 / 투자 / 부동산 / 기타 자산 / 신용카드 / 대출·부채 입력·수정·삭제
- **가계부**: 지출·수입·**이체** 기록(분류·날짜·메모), 월별 합계, 분류별 지출 막대
- **이체** (v1.1): 통장·예금에서 적금·기타 자산(저축보험 등)·대출로 보낸 돈 기록 → 보내는 곳은 **−**, 받는 곳은 **+**, 순자산은 그대로
- **계좌 연결**: 가계부에서 계좌를 고르면 그 금액이 자동으로 바뀜 (모든 자산 종류 선택 가능, 카드·마이너스통장은 부채가 늘어남)
- **계좌 상세** (v1.1): 자산을 누르면 금액이 바뀐 기록(나간 돈 −, 들어온 돈 +)을 보고 바로 수정·이체
- **카드** 탭 (v1.2): 카드로 쓴 돈은 가계부 지출로 잡히고 카드의 '결제할 금액'에 쌓였다가, **[카드값 결제]**를 기록할 때 통장에서 빠져요. 카드별 이번 달 사용액·결제할 금액·결제일 알림
- **기간 통계** (v1.3): 가계부 탭의 **[기간 통계]**에서 최대 12개월 동안의 **분류별 수입·지출 총액**. 분류를 누르면 월별 금액과 기록이 나와요
- **문자·알림으로 기록** (v1.4~1.6): 은행·카드 앱의 **알림**이나 **문자**를 넣으면(자동화 앱·공유·붙여넣기) 금액·날짜·내용·계좌를 읽어요. 자동화 앱이 넘긴 알림은 **받은 알림함**에 쌓였다가 한 번에 처리하고, 확실한 건 바로 기록해요. 내 계좌끼리 옮긴 돈은 이체 하나로 합쳐요
- **설정**: 백업 파일 저장·보내기·불러오기, 전체 삭제
- 오른쪽 위 눈 모양 버튼: 금액 숨기기

## 파일 구성 (7개)

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 전체 (화면 + 디자인 + 동작 코드) |
| `manifest.webmanifest` | 앱 이름·아이콘 같은 "설치 정보" |
| `sw.js` | 인터넷 없이도 앱이 열리게 해 주는 파일 (서비스워커) |
| `icon-192.png`, `icon-512.png`, `icon-maskable-512.png` | 앱 아이콘 |
| `README.md` | 이 설명서 |

## 휴대폰에 설치하는 방법 (처음 한 번, 약 10분)

웹앱은 인터넷 주소가 있어야 폰에 설치할 수 있어요.
무료 서비스인 **GitHub Pages**에 파일을 올려서 나만의 주소를 만듭니다. (PC에서 하는 게 편해요)

### 1단계. GitHub 가입 (이미 있으면 건너뛰기)

1. <https://github.com> 접속 → **Sign up** → 이메일·비밀번호·아이디 입력
2. 아이디는 앱 주소에 들어가요. 예) 아이디가 `hong123`이면 → `https://hong123.github.io/...`

### 2단계. 저장소(Repository) 만들기

1. 로그인 후 오른쪽 위 **+** → **New repository**
2. Repository name: `my-asset` (영어 소문자 추천)
3. **Public** 선택 (무료 계정은 Public이어야 Pages를 쓸 수 있어요. 공개되는 건 앱 코드뿐이고, 입력한 자산 데이터는 공개되지 않아요)
4. **Create repository** 클릭

### 3단계. 파일 올리기

1. 받은 `my-asset-app.zip`을 PC에서 **압축 풀기**
2. 방금 만든 저장소 화면에서 **uploading an existing file** 링크 클릭
3. 압축 푼 폴더 **안의 파일 7개**를 모두 선택해서 끌어다 놓기 (폴더째가 아니라 파일들만)
4. 아래쪽 **Commit changes** 클릭

### 4단계. GitHub Pages 켜기

1. 저장소 위쪽 메뉴 **Settings** → 왼쪽 메뉴 **Pages**
2. Build and deployment → Source: **Deploy from a branch**
3. Branch: **main**, 폴더: **/ (root)** → **Save**
4. 1~2분 뒤 새로고침하면 위쪽에 **Your site is live at …** 과 함께 주소가 나와요
   예) `https://hong123.github.io/my-asset/`

### 5단계. 갤럭시에 설치

1. 폰에서 **크롬(Chrome)** 앱을 열고 위 주소로 접속
   (카카오톡 안에서 링크를 바로 열지 말고, 주소를 복사해서 **크롬 주소창**에 붙여넣으세요)
2. 앱 화면 위쪽의 **[설치]** 버튼을 누르거나, 크롬 오른쪽 위 **⋮ → 홈 화면에 추가 → 설치**
   ('바로가기 만들기'가 아니라 **설치**를 고르세요. 메뉴에 '앱 설치'가 보이면 그걸 눌러도 돼요)
3. 홈 화면(또는 앱스 화면)에 생긴 **내 자산관리** 아이콘으로 실행하면 끝!

## 처음 사용 순서

1. **자산** 탭 → **+** → 종류(현금·통장, 예금 …) 고르고 이름·금액 입력
2. **가계부** 탭 → **+** → 지출/수입, 금액, 분류 고르고 **기록하기**
   - "어느 계좌에서?"에서 통장을 고르면 그 통장 잔액이 자동으로 줄거나 늘어요
3. **홈**에서 순자산 확인

### 이체 기록하기 (예: 통장 → 저축보험·적금)

1. 저축보험처럼 따로 모으는 돈은 먼저 **자산** 탭에서 **기타 자산**(또는 적금)으로 등록해 두세요
2. **가계부** 탭 → **+** → 맨 위에서 **이체** 선택
3. 금액 입력 → **보내는 곳**(예: 국민은행 통장) → **받는 곳**(예: 저축보험) 고르기 → **이체 기록하기**
   - 아래 파란 안내에 "국민은행 통장 −300,000원 → 저축보험 +300,000원"처럼 미리 보여줘요
4. **자산** 탭에서 통장 아래에는 "최근 −300,000원", 저축보험 아래에는 "최근 +300,000원"이 표시돼요
   - 자산을 누르면 그 계좌의 기록 전체와 [이체하기] 버튼이 나와요
   - 대출을 누르고 **[갚기 (이체)]**를 쓰면 통장은 줄고 대출(부채)도 줄어요
- 이체는 내 돈이 옮겨간 것이라 이번 달 **수입·지출 합계에는 들어가지 않고**, "이체 (계좌 간 이동)" 줄에 따로 보여요

### 잔액 계산 규칙

- 계좌 잔액 = **마지막으로 직접 입력한 금액** + 그 뒤에 이 계좌로 기록한 (수입 − 지출)
- 은행 앱 잔액과 다르면 자산 탭에서 **잔액을 직접 고치세요**. 고친 금액이 새 기준이 됩니다.
- 대출·부채 항목(카드값, 마이너스통장)을 결제수단으로 고르면 쓴 만큼 **부채가 늘어나요**.

### 신용카드 쓰는 법 (v1.2)

1. **카드** 탭 → **+**(또는 [신용카드 추가하기]) → 카드 이름, **아직 결제 안 한 카드값**(카드 앱의 '결제 예정 금액', 없으면 0), **결제일**, **결제 통장** 입력
2. 카드로 결제했을 때: 카드 탭의 **+** 또는 가계부 **+** → **결제수단**에서 카드 선택 → **기록하기**
   - 가계부 **지출로 잡히고**, 카드의 **결제할 금액**이 늘어나요. 통장 잔액은 **그대로**예요.
   - 순자산은 줄어들어요 (갚아야 할 카드값이 생겼으니까요).
3. 카드값이 통장에서 빠져나갔을 때: 카드 탭 → **[카드값 결제]**
   - **지난달까지 쓴 금액**이 미리 채워져요. 카드 앱의 청구 금액과 다르면 숫자를 고치거나 [결제할 금액 전체] 버튼을 누르세요.
   - **통장 −, 카드값 −** 로 기록되고, 이미 지출로 잡힌 돈이라 **지출로 두 번 잡히지 않아요**. 순자산도 그대로예요.
4. 결제일에는 홈과 카드 탭에 **"오늘은 ○○카드 결제일이에요"** 알림이 떠요. 결제를 기록하면 사라져요.

- **체크카드**는 통장에서 바로 빠지니, 결제수단으로 **통장**을 고르세요.
- 예전에 **대출·부채**에 카드값을 넣어 두셨다면: 그 항목을 열고 [수정] → 종류를 **신용카드**로 바꾸면 카드 탭으로 옮겨와요 (금액·기록 그대로).
- 카드 결제를 취소했으면 그 지출 기록을 지우거나 금액을 고치세요.

### 기간 통계 보는 법 (v1.3)

**가계부** 탭 맨 위의 **[기간 통계]**를 누르면, 고른 기간(최대 12개월) 동안의 수입·지출을 **분류별 총액**으로 보여줘요.

1. **기간 고르기**: [이번 달] [지난달] [최근 3개월] [올해] [최근 12개월] 버튼을 누르거나, 아래 두 칸에서 **시작 월 ~ 끝 월**을 직접 고르세요
   - 12개월보다 길게 고르면 자동으로 12개월에 맞춰져요
2. **수입 분류별** · **지출 분류별**에서 분류마다 합계와 비율(%)을 봐요. 맨 아래 줄이 그 기간의 **수입 합계 / 지출 합계**예요
3. 분류를 누르면 그 분류의 **월별 금액**과 **기록 목록**이 나와요. 기록을 누르면 바로 고칠 수 있어요
4. 2개월 이상 고르면 맨 아래에 **월별 합계** 표(월마다 수입·지출·남은 돈)가 나와요

예시:

| 보고 싶은 것 | 이렇게 하세요 |
|---|---|
| 8월 부수입 1개월치 | 기간을 **2026년 8월 ~ 2026년 8월**로 → 수입 분류별의 **부수입** |
| 8월 급여와 수입 총액 | 같은 화면의 **급여** 줄과 맨 아래 **수입 합계** (위쪽 요약의 '수입'과 같은 금액) |
| 1·2·3월 식비 총액 | 기간을 **2026년 1월 ~ 2026년 3월**로 → 지출 분류별의 **식비** (누르면 1월·2월·3월 각각과 월평균) |

- **월별 내역**의 '분류별 지출' 오른쪽 **[기간 통계 ›]**를 누르면 보고 있던 달의 통계로 바로 가요
- **이체**(계좌 간 이동)와 **카드값 결제**는 내 돈이 옮겨간 것이라 수입·지출 합계에 넣지 않아요. 카드로 쓴 돈은 **쓴 날짜의 지출**로 들어가요
- 눈 모양 버튼으로 금액을 숨기면 통계 금액도 함께 숨겨져요

### 문자·알림으로 기록하기 (v1.4 · v1.5)

먼저 알아둘 것: 이 앱은 웹앱이라 **폰의 문자함이나 알림을 스스로 읽을 수는 없어요** (안드로이드가 보안상 막아 두었어요).
대신 문자·알림을 앱에 **넣어 주면**, 앱이 금액·입금/출금·날짜·내용(가게·보낸 사람)·은행/카드를 읽어서 기록해요.
넣는 방법은 네 가지인데, **은행 앱 알림을 자동으로 넣는 방법(A)** 이 가장 편해요.

**방법 A. 은행·카드 앱 알림 → 받은 알림함 (추천, 자동화 앱 필요)**

무료 자동화 앱 **MacroDroid(매크로드로이드)** 가 은행 앱 알림(i-ONE뱅크, 우리WON뱅킹, 신한 슈퍼SOL, 카드 앱 …)을 보고 앱 주소를 열어 줘요. 앱은 열리자마자 알림을 **받은 알림함**에 담아요. 그 자리에서 기록할 필요 없어요. 알림이 연달아 와도 앞의 알림이 사라지지 않고, 나중에 앱을 열어서 **한 번에 처리**하면 돼요.

1. Play 스토어에서 **MacroDroid** 설치 → 처음 켤 때 **알림 접근(알림 읽기) 권한**을 허용 (설정 → 알림 → 기기 및 앱 알림 → MacroDroid 켜기로 가기도 해요)
2. **매크로 추가** → 이름: `은행 알림 가계부`
3. **트리거(+)** → **기기 관련 변동(기기 이벤트)** → **알림** → **알림 수신** → **애플리케이션 선택**에서 은행·카드 앱을 모두 체크 → 내용 필터는 "모두" → **'중복 트리거 방지'** 가 있으면 체크 → 확인
4. **액션(+)** → **애플리케이션** → **웹사이트 열기** → 주소 칸에 앱의 **설정 → '자동화 앱에서 열 주소 — 앱 알림용'** 을 [복사]해서 그대로 붙여넣기
   - 예) `https://아이디.github.io/my-asset/?app={not_app_name}&title={not_title}&text={notification}`
   - `{ }` 부분은 MacroDroid가 알림을 보낸 앱 이름·제목·내용으로 바꿔 넣는 자리예요. 주소 칸 옆 **…(매직 텍스트)** 버튼에서 '알림 앱 이름', '알림 제목', '알림 텍스트'를 골라 넣어도 같아요
   - 브라우저를 고르라고 하면 **Chrome**. 앱 목록에 '내 자산관리'가 없어도 괜찮아요 (크롬이 주소를 열면 앱으로 연결돼요)
5. 저장(✓) → 매크로를 **활성화** → 이제 은행 알림이 오면 앱이 잠깐 열리면서 알림을 담아 두고 "📩 알림을 받아 두었어요 · 확인할 알림 N건"이라고 알려줘요

**받은 알림함에서 한 번에 처리하기**

- 홈·가계부 맨 위의 **"📩 확인할 알림 N건 [처리하기]"** 또는 설정 → **[받은 알림함 열기]**
- 알림마다 읽은 내용(지출/수입 · 금액 · 상대 · 계좌)이 보여요. **[기록]** 을 누르면 채워진 입력창이 열리고, [기록하기]를 누르면 다음 알림으로 넘어가요. 관계없는 알림은 **[건너뛰기]**
- 계좌까지 확실한 알림이 있으면 맨 위에 **[확실한 알림 N건 한 번에 기록]** 버튼이 떠요. 온 순서대로 기록하니 내 계좌 간 이체(출금+입금)도 하나로 합쳐져요
- 못 읽은 알림은 "못 읽음: 이유"로 보여요. [내용 보고 기록]으로 직접 고치거나 건너뛰세요
- 처리한 알림은 아래 "처리한 알림 N건"에 남고, [처리한 알림 비우기]로 지울 수 있어요

**바로 기록 (설정 → '확실하면 바로 기록')**

- 켜 두면(기본) 계좌(카드)가 하나로 정해지는 알림은 알림함에 담는 동시에 **바로 가계부에 기록**하고, 가계부 위에 "📩 알림으로 자동 기록했어요" 배너([고치기]·[지우기])를 띄워요. 애매한 알림만 알림함에 남아요
- 끄면 모든 알림이 알림함에 남고, 알림함에서 [기록] 또는 [확실한 알림 N건 한 번에 기록]으로 처리해요
- 같은 은행 계좌가 여럿이면(기업은행 01-013과 04-015처럼) → 자산 수정의 **'문자 식별 단어'** 에 알림에 나오는 끝자리(예 `01-013`)를 넣어 두세요. 안 넣으면 '계좌 모름/외 1개'로 남아서 입력창에서 직접 고르게 돼요

**작성 중이던 기록은 지켜져요**: 입력창을 쓰는 중에 알림이 와서 앱이 다시 열려도, 홈·가계부 위에 **"✍️ 작성 중이던 기록이 있어요 [이어서 쓰기]"** 배너가 떠요. 쓰던 금액·메모·계좌 그대로 이어서 쓸 수 있어요. 입력창을 직접 닫으면 버려져요.

**내 계좌끼리 옮긴 돈 → 이체 하나로**: 통장 A에서 통장 B로 보내면 A의 '출금' 알림과 B의 '입금' 알림이 하나씩 와요. 앱은 **같은 금액 · 반대 방향 · 서로 다른 내 통장**이면 둘을 **이체 하나**로 합쳐요. 지출·수입으로 잡히지 않아요. 출금 알림 뒤 **5분 안에** 같은 금액 입금 알림이 오면 상대 이름이 달라도 합치고, 2시간 안이면 상대 이름이 같을 때(또는 내 이름일 때) 합쳐요.
- 바로 기록된 것끼리든, 알림함에서 나중에 [기록]한 것이든, 하나는 바로 기록되고 하나는 입력창에서 기록한 것이든 모두 합쳐져요. 두 번째를 기록하는 순간 "🔁 이체로 합쳤어요: A → B"라고 알려줘요.
- 설정에 **내 이름**을 꼭 넣어 두세요. 상대 이름이 내 이름이면 첫 알림부터 이체로 두고 상대 계좌 알림을 기다려요. 상대 계좌가 등록되지 않은 은행이면 "보낸 곳 확인 필요"로 남으니 눌러서 골라 주세요.
- 이미 지출·수입 2건으로 잡혀 있으면 가계부(월별 내역) 위에 **"🔁 같은 금액의 출금·입금이 N쌍 있어요 [이체로 합치기]"** 가 떠요. 누르면 한 번에 합쳐져요. 내 계좌 간 이체가 아니면 [아니요].
- 5분이 지난 뒤에 온 같은 금액 입금은 상대 이름이 같을 때만 합쳐요. (예: 홍길동에게 보낸 5만 원과 한참 뒤 김철수에게 받은 5만 원은 따로) 알림끼리 30분 안이면 가계부 배너로 합칠지 물어봐요.

**방법 B. 공유 (추가 앱 없음)**

1. 문자 앱에서 은행·카드 문자를 **길게 누르기** → **공유** → **내 자산관리**
2. 확실하면 바로 기록되고, 아니면 채워진 입력창이 열려요 → **[기록하기]**

> 공유 목록에 '내 자산관리'가 보이려면 v1.4 업데이트(manifest 파일) 뒤에 크롬이 앱 정보를 새로 받아야 해요.
> 며칠 걸릴 수 있어요. 그동안은 방법 C를 쓰세요. (앱을 지웠다 깔 필요 없어요)

**방법 C. 붙여넣기**

1. 문자나 알림 내용을 복사
2. 앱의 가계부 **+** → 위쪽 **[📩 문자 붙여넣기]** (또는 설정 → **[문자·알림 붙여넣어 기록]**)
3. **[클립보드에서 붙여넣기]** → 읽은 내용이 표로 보여요 → **[입력창 열기]** → **[기록하기]**
   - 붙여넣기를 허용하겠냐고 물으면 허용하세요. 안 되면 입력칸을 길게 눌러 붙여넣고 **[읽기]**
   - 알림 내용에 은행 이름이 없으면(신한 슈퍼SOL처럼) 맨 앞에 `신한` 같은 은행 이름을 적어 주세요

**방법 D. 문자(SMS) 자동** — MacroDroid 트리거를 **SMS 수신**으로, 주소는 설정의 **'문자(SMS)용'** 주소(`…?sms={sms_message}`)로 만들면 방법 A와 똑같이 돼요.

**매크로는 돌았는데 앱에서 아무 반응이 없을 때**
- 앱의 **설정 → 최근 받은 알림(진단용)** 을 보세요. 자동화 앱이 앱을 열 때마다 무엇이 들어왔는지 남아요.
  - 목록이 **비어 있으면** → 앱이 주소 없이 열린 거예요. MacroDroid 액션이 '앱 실행'이 아니라 **'웹사이트 열기'**인지, 주소가 설정의 주소와 같은지 확인하세요.
  - **"빈 내용/그대로 옴"** 이면 → 주소의 `{ }` 부분이 알림 내용으로 안 바뀐 거예요. MacroDroid 주소 칸 옆 **…(매직 텍스트)** 버튼으로 '알림 앱 이름', '알림 제목', '알림 텍스트'를 골라 다시 넣으세요. 알림 트리거에 '문자(SMS)용' 주소를 쓴 경우도 비어서 와요.
  - **"못 읽음"** 이면 → 그 줄을 **[기록 복사]** 해서 보내 주세요. 형식을 추가할 수 있어요.
- 홈·가계부 위에 노란 **"자동화 앱 설정을 확인해 주세요"** 배너가 뜨면 거기 적힌 대로 고치면 돼요.

주의할 점
- 폰의 **기본 브라우저가 크롬**이어야 해요. (삼성 인터넷이면: 설정 → 애플리케이션 → 기본 앱 선택 → 브라우저 앱 → Chrome)
- 알림이 올 때마다 앱이 잠깐 열려요. 웹앱이라 몰래 뒤에서 기록할 수는 없어요.
- MacroDroid 무료 버전은 매크로 5개까지예요. 알림용 1개(+문자용 1개)면 돼요.
- 은행 앱의 **입출금 알림(푸시)** 이 켜져 있어야 해요 (각 은행 앱의 알림 설정에서).

**읽는 규칙과 팁**

- **계좌 찾기**: 알림을 보낸 앱 이름(i-ONE뱅크 → 기업은행, 우리WON뱅킹 → 우리은행, 신한 슈퍼SOL → 신한은행, KB스타뱅킹 → 국민은행 …)이나 문자 맨 앞의 은행·카드사 이름과 같은 이름이 들어간 내 자산을 골라요. 그래서 자산 이름에 **은행·카드사 이름**(예: `기업은행 통장`, `신한카드`)을 넣어 두는 게 좋아요.
- **잔액·누적 금액은 빼고** 거래 금액만 읽어요. 할부 문자는 전체 금액이 들어가요.
- **승인취소·환불** 문자는 돌려받은 돈(수입)으로 기록해요.
- 통장 알림에 **내 카드 이름**(예: 신한카드)이 있으면 **카드값 결제(이체)** 로 기록해요.
- 같은 알림이 두 번 오면 한 번만 기록해요. 입력창으로 열렸을 때 같은 날 같은 금액이 이미 있으면 노란 안내가 떠요.
- 자동으로 기록된 줄에는 **📩** 표시가 붙어요. 누르면 보통 기록처럼 고칠 수 있어요.
- **못 읽는 알림·문자**가 있으면 그 내용을 복사해서 보내 주시면 형식을 추가할 수 있어요. (지금 확인된 형식: 신한은행 문자, i-ONE뱅크·우리WON뱅킹·신한 슈퍼SOL 알림. 다른 은행·카드사는 주요 형식만 넣어 두었어요)

## 데이터와 백업 (중요)

- 입력한 데이터는 **이 휴대폰의 크롬 저장소에만** 있어요. 어디로도 전송되지 않아요.
- GitHub에 올린 앱 파일과는 **따로** 저장돼서, 앱 파일을 바꿔(업데이트해)도 데이터는 그대로예요.
- 대신 **크롬의 '쿠키 및 사이트 데이터' 삭제, 휴대폰 교체·초기화** 때는 사라질 수 있어요.
- 항상 **홈 화면의 앱 아이콘**으로 여세요. 삼성 인터넷이나 카톡 안에서 열면 저장소가 달라서 빈 화면처럼 보여요 (데이터가 지워진 건 아니에요).
- **설정 → 백업 파일 저장**(또는 **보내기**로 카톡·구글드라이브에 보관)을 가끔, 특히 **업데이트 전에** 해 두세요.
- 새 폰에서는 앱 설치 후 **설정 → 백업 파일 불러오기**로 그대로 옮길 수 있어요.

## 새 버전으로 업데이트하기 (이미 폰에 설치해서 쓰는 중이라면)

앱을 지우거나 다시 설치할 필요 없어요. GitHub의 파일만 바꾸면 폰 앱이 다음에 열 때 새 버전으로 바뀌어요.

0. (권장) 폰 앱 **설정 → 백업 파일 저장**
1. PC에서 새 `my-asset-app.zip` 압축 풀기
2. GitHub 저장소 → **Add file → Upload files** → 폴더 안의 `index.html`, `sw.js`, `README.md` 3개를 끌어다 놓기 (같은 이름은 자동으로 덮어써져요. v1.4를 건너뛰고 올라오는 거면 `manifest.webmanifest`도 함께)
3. **Commit changes** 클릭 → 1~2분 기다리기
4. 폰에서 앱을 **완전히 닫았다가 다시 열기** → **설정** 맨 아래가 새 버전(이번엔 **v1.6.1**)이면 완료
   - 안 바뀌면 10분쯤 뒤 한 번 더 닫았다 열어 보세요 (GitHub 캐시)
5. 이미 입력한 자산·가계부 데이터는 **그대로** 남아요 (새 버전이 자동으로 읽어요)

> 아직 GitHub에 올리기 전이라면, 위의 "휴대폰에 설치하는 방법"대로 새 zip의 파일 7개를 처음부터 올리면 돼요.
> 크롬의 '쿠키 및 사이트 데이터' 삭제나 앱 삭제는 하지 마세요 — 데이터가 지워질 수 있어요.

> 주의: GitHub 아이디를 바꾸거나 다른 사이트로 옮겨서 주소 앞부분(`https://아이디.github.io`)이 달라지면,
> 폰 입장에선 다른 앱이라 데이터가 보이지 않아요. 그럴 땐 먼저 백업 → 새 주소에서 불러오기를 하세요.
> (저장소 이름만 바꾸면 데이터는 남지만, 홈 화면 앱은 새 주소로 다시 설치해야 해요)

## PC에서 미리 보기

압축 푼 폴더의 `index.html`을 더블클릭하면 PC 브라우저에서 바로 열어볼 수 있어요.
(PC에서 입력한 데이터는 폰과 따로 저장돼요)
