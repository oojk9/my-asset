# 내 자산관리 (v1.2.0)

예금·적금·투자·부동산·대출 같은 **내 자산**과 **매일의 가계부**를 기록해서
**순자산(총자산 − 총부채)** 을 한눈에 보는 개인용 앱입니다.
갤럭시(안드로이드) 크롬에서 **홈 화면에 설치**해 앱처럼 쓰는 웹앱(PWA)이에요.

## 이 앱이 하는 일

- **홈**: 순자산 · 총자산 · 총부채, 자산 구성 비율, 이번 달 수입/지출, 최근 기록
- **자산**: 현금·통장 / 예금 / 적금 / 투자 / 부동산 / 기타 자산 / 신용카드 / 대출·부채 입력·수정·삭제
- **가계부**: 지출·수입·**이체** 기록(분류·날짜·메모), 월별 합계, 분류별 지출 막대
- **이체** (v1.1): 통장·예금에서 적금·기타 자산(저축보험 등)·대출로 보낸 돈 기록 → 보내는 곳은 **−**, 받는 곳은 **+**, 순자산은 그대로
- **계좌 연결**: 가계부에서 계좌를 고르면 그 금액이 자동으로 바뀜 (모든 자산 종류 선택 가능, 카드·마이너스통장은 부채가 늘어남)
- **계좌 상세** (v1.1): 자산을 누르면 금액이 바뀐 기록(나간 돈 −, 들어온 돈 +)을 보고 바로 수정·이체
- **카드** 탭 (v1.2): 카드로 쓴 돈은 가계부 지출로 잡히고 카드의 '결제할 금액'에 쌓였다가, **[카드값 결제]**를 기록할 때 통장에서 빠져요. 카드별 이번 달 사용액·결제할 금액·결제일 알림
- **설정**: 백업 파일 저장·보내기·불러오기, 전체 삭제
- 오른쪽 위 눈 모양 버튼: 금액 숨기기

## 파일 구성 (7개)

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 전체 (화면 + 디자인 + 동작 코드) |
| `manifest.webmanifest` | 앱 이름·아이콘 같은 "설치 정보" |
| `sw.js` | 인터넷 없이도 앱이 열리게 해 주는 파일 (서비스워커) |
| `icon-192.png`, `icon-512.png`, `icon-maskable-512.png` | 앱 아이콘 |
| `README.md` | 이 설명서 |

## 휴대폰에 설치하는 방법 (처음 한 번, 약 10분)

웹앱은 인터넷 주소가 있어야 폰에 설치할 수 있어요.
무료 서비스인 **GitHub Pages**에 파일을 올려서 나만의 주소를 만듭니다. (PC에서 하는 게 편해요)

### 1단계. GitHub 가입 (이미 있으면 건너뛰기)

1. <https://github.com> 접속 → **Sign up** → 이메일·비밀번호·아이디 입력
2. 아이디는 앱 주소에 들어가요. 예) 아이디가 `hong123`이면 → `https://hong123.github.io/...`

### 2단계. 저장소(Repository) 만들기

1. 로그인 후 오른쪽 위 **+** → **New repository**
2. Repository name: `my-asset` (영어 소문자 추천)
3. **Public** 선택 (무료 계정은 Public이어야 Pages를 쓸 수 있어요. 공개되는 건 앱 코드뿐이고, 입력한 자산 데이터는 공개되지 않아요)
4. **Create repository** 클릭

### 3단계. 파일 올리기

1. 받은 `my-asset-app.zip`을 PC에서 **압축 풀기**
2. 방금 만든 저장소 화면에서 **uploading an existing file** 링크 클릭
3. 압축 푼 폴더 **안의 파일 7개**를 모두 선택해서 끌어다 놓기 (폴더째가 아니라 파일들만)
4. 아래쪽 **Commit changes** 클릭

### 4단계. GitHub Pages 켜기

1. 저장소 위쪽 메뉴 **Settings** → 왼쪽 메뉴 **Pages**
2. Build and deployment → Source: **Deploy from a branch**
3. Branch: **main**, 폴더: **/ (root)** → **Save**
4. 1~2분 뒤 새로고침하면 위쪽에 **Your site is live at …** 과 함께 주소가 나와요
   예) `https://hong123.github.io/my-asset/`

### 5단계. 갤럭시에 설치

1. 폰에서 **크롬(Chrome)** 앱을 열고 위 주소로 접속
   (카카오톡 안에서 링크를 바로 열지 말고, 주소를 복사해서 **크롬 주소창**에 붙여넣으세요)
2. 앱 화면 위쪽의 **[설치]** 버튼을 누르거나, 크롬 오른쪽 위 **⋮ → 홈 화면에 추가 → 설치**
   ('바로가기 만들기'가 아니라 **설치**를 고르세요. 메뉴에 '앱 설치'가 보이면 그걸 눌러도 돼요)
3. 홈 화면(또는 앱스 화면)에 생긴 **내 자산관리** 아이콘으로 실행하면 끝!

## 처음 사용 순서

1. **자산** 탭 → **+** → 종류(현금·통장, 예금 …) 고르고 이름·금액 입력
2. **가계부** 탭 → **+** → 지출/수입, 금액, 분류 고르고 **기록하기**
   - "어느 계좌에서?"에서 통장을 고르면 그 통장 잔액이 자동으로 줄거나 늘어요
3. **홈**에서 순자산 확인

### 이체 기록하기 (예: 통장 → 저축보험·적금)

1. 저축보험처럼 따로 모으는 돈은 먼저 **자산** 탭에서 **기타 자산**(또는 적금)으로 등록해 두세요
2. **가계부** 탭 → **+** → 맨 위에서 **이체** 선택
3. 금액 입력 → **보내는 곳**(예: 국민은행 통장) → **받는 곳**(예: 저축보험) 고르기 → **이체 기록하기**
   - 아래 파란 안내에 "국민은행 통장 −300,000원 → 저축보험 +300,000원"처럼 미리 보여줘요
4. **자산** 탭에서 통장 아래에는 "최근 −300,000원", 저축보험 아래에는 "최근 +300,000원"이 표시돼요
   - 자산을 누르면 그 계좌의 기록 전체와 [이체하기] 버튼이 나와요
   - 대출을 누르고 **[갚기 (이체)]**를 쓰면 통장은 줄고 대출(부채)도 줄어요
- 이체는 내 돈이 옮겨간 것이라 이번 달 **수입·지출 합계에는 들어가지 않고**, "이체 (계좌 간 이동)" 줄에 따로 보여요

### 잔액 계산 규칙

- 계좌 잔액 = **마지막으로 직접 입력한 금액** + 그 뒤에 이 계좌로 기록한 (수입 − 지출)
- 은행 앱 잔액과 다르면 자산 탭에서 **잔액을 직접 고치세요**. 고친 금액이 새 기준이 됩니다.
- 대출·부채 항목(카드값, 마이너스통장)을 결제수단으로 고르면 쓴 만큼 **부채가 늘어나요**.

### 신용카드 쓰는 법 (v1.2)

1. **카드** 탭 → **+**(또는 [신용카드 추가하기]) → 카드 이름, **아직 결제 안 한 카드값**(카드 앱의 '결제 예정 금액', 없으면 0), **결제일**, **결제 통장** 입력
2. 카드로 결제했을 때: 카드 탭의 **+** 또는 가계부 **+** → **결제수단**에서 카드 선택 → **기록하기**
   - 가계부 **지출로 잡히고**, 카드의 **결제할 금액**이 늘어나요. 통장 잔액은 **그대로**예요.
   - 순자산은 줄어들어요 (갚아야 할 카드값이 생겼으니까요).
3. 카드값이 통장에서 빠져나갔을 때: 카드 탭 → **[카드값 결제]**
   - **지난달까지 쓴 금액**이 미리 채워져요. 카드 앱의 청구 금액과 다르면 숫자를 고치거나 [결제할 금액 전체] 버튼을 누르세요.
   - **통장 −, 카드값 −** 로 기록되고, 이미 지출로 잡힌 돈이라 **지출로 두 번 잡히지 않아요**. 순자산도 그대로예요.
4. 결제일에는 홈과 카드 탭에 **"오늘은 ○○카드 결제일이에요"** 알림이 떠요. 결제를 기록하면 사라져요.

- **체크카드**는 통장에서 바로 빠지니, 결제수단으로 **통장**을 고르세요.
- 예전에 **대출·부채**에 카드값을 넣어 두셨다면: 그 항목을 열고 [수정] → 종류를 **신용카드**로 바꾸면 카드 탭으로 옮겨와요 (금액·기록 그대로).
- 카드 결제를 취소했으면 그 지출 기록을 지우거나 금액을 고치세요.

## 데이터와 백업 (중요)

- 입력한 데이터는 **이 휴대폰의 크롬 저장소에만** 있어요. 어디로도 전송되지 않아요.
- GitHub에 올린 앱 파일과는 **따로** 저장돼서, 앱 파일을 바꿔(업데이트해)도 데이터는 그대로예요.
- 대신 **크롬의 '쿠키 및 사이트 데이터' 삭제, 휴대폰 교체·초기화** 때는 사라질 수 있어요.
- 항상 **홈 화면의 앱 아이콘**으로 여세요. 삼성 인터넷이나 카톡 안에서 열면 저장소가 달라서 빈 화면처럼 보여요 (데이터가 지워진 건 아니에요).
- **설정 → 백업 파일 저장**(또는 **보내기**로 카톡·구글드라이브에 보관)을 가끔, 특히 **업데이트 전에** 해 두세요.
- 새 폰에서는 앱 설치 후 **설정 → 백업 파일 불러오기**로 그대로 옮길 수 있어요.

## 새 버전으로 업데이트하기 (이미 폰에 설치해서 쓰는 중이라면)

앱을 지우거나 다시 설치할 필요 없어요. GitHub의 파일만 바꾸면 폰 앱이 다음에 열 때 새 버전으로 바뀌어요.

0. (권장) 폰 앱 **설정 → 백업 파일 저장**
1. PC에서 새 `my-asset-app.zip` 압축 풀기
2. GitHub 저장소 → **Add file → Upload files** → 폴더 안의 `index.html`, `sw.js`, `README.md` 3개를 끌어다 놓기 (같은 이름은 자동으로 덮어써져요)
3. **Commit changes** 클릭 → 1~2분 기다리기
4. 폰에서 앱을 **완전히 닫았다가 다시 열기** → **설정** 맨 아래가 새 버전(이번엔 **v1.2.0**)이면 완료
   - 안 바뀌면 10분쯤 뒤 한 번 더 닫았다 열어 보세요 (GitHub 캐시)
5. 이미 입력한 자산·가계부 데이터는 **그대로** 남아요 (새 버전이 자동으로 읽어요)

> 아직 GitHub에 올리기 전이라면, 위의 "휴대폰에 설치하는 방법"대로 새 zip의 파일 7개를 처음부터 올리면 돼요.
> 크롬의 '쿠키 및 사이트 데이터' 삭제나 앱 삭제는 하지 마세요 — 데이터가 지워질 수 있어요.

> 주의: GitHub 아이디를 바꾸거나 다른 사이트로 옮겨서 주소 앞부분(`https://아이디.github.io`)이 달라지면,
> 폰 입장에선 다른 앱이라 데이터가 보이지 않아요. 그럴 땐 먼저 백업 → 새 주소에서 불러오기를 하세요.
> (저장소 이름만 바꾸면 데이터는 남지만, 홈 화면 앱은 새 주소로 다시 설치해야 해요)

## PC에서 미리 보기

압축 푼 폴더의 `index.html`을 더블클릭하면 PC 브라우저에서 바로 열어볼 수 있어요.
(PC에서 입력한 데이터는 폰과 따로 저장돼요)
